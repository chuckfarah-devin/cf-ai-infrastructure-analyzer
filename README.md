# CF AI Infrastructure Analyzer

## What is it?
Interactive simulation of how distributed solar, EV batteries and home storage might offset/reshape grid demand associated with AI infrastructure in Florida.

## Why build it?
To demonstrate product thinking, infrastructure modeling, data visualization and Specification-Driven/AI-assisted development.

## How is it being built?
React + TypeScript + agentic development using Devin/Claude and Windsurf/SWE.

## Status
Business specification complete → technical specification underway → implementation in progress.
